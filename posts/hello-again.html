Rebuilding this site from scratch

2026-07-07 · meta · ~2 min read

For years this domain pointed at the default GitHub Pages tutorial — a spinning octocat and the line "Hello World! I'm Leiren." It did its job: the site was live. But it was never mine.

So I tore it down and rebuilt it as what I actually wanted: a quiet, monospace place to write. No framework, no build step, no 200KB of JavaScript to render a paragraph. Just HTML and one stylesheet you can read top to bottom.

the whole stack

Here's the entire dependency list:

index.html    # home
blog.html     # the list of posts
posts/*.html  # the posts themselves
styles.css    # ~250 lines, light + dark

That's it. It loads instantly, works with JavaScript disabled, and I can understand every line six months from now.

The best stack is the one you can hold in your head.

what's next

More writing, mostly. If I ever grow tired of hand-editing HTML I'll add a tiny generator — but not before I actually need one.
